# Code of conduct

CloudNativePatroni adopts the Contributor Covenant, version 2.1, as its code of
conduct. The full text is published at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and is
licensed under CC BY 4.0.

In short: participants are expected to behave respectfully and professionally.
Harassment, personal attacks, and discriminatory conduct are not tolerated, in
this repository or in any space where someone is representing the project.

## Reporting

Report conduct concerns to the maintainers, who are identified in
[`MAINTAINERS.md`](MAINTAINERS.md).

This project does not yet publish a dedicated, confidential reporting address,
and that is a known gap rather than an oversight; it is recorded here so that
nobody assumes a process exists that does not. A reporting address will be
published together with the maintainer list.

Reports about this project must not be sent to the CloudNativePG project's
conduct contacts. It is a separate project with separate maintainers.

> CloudNativePatroni is an independent project derived from CloudNativePG. It is not affiliated
> with or endorsed by CloudNativePG, CNCF, LF Projects, or the Patroni maintainers.
