# Maintainers

CloudNativePatroni is a personal project maintained by one individual.

The maintainer's identity is not published here. The project is a pre-alpha
architecture spike with no external contributors.

Decision-making is described in [`GOVERNANCE.md`](GOVERNANCE.md).

This project does not share maintainers with CloudNativePG, and the
CloudNativePG maintainers are not responsible for it in any way.

> CloudNativePatroni is an independent project derived from CloudNativePG. It is not affiliated
> with or endorsed by CloudNativePG, CNCF, LF Projects, or the Patroni maintainers.
